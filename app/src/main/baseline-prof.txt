# ohagi app code baseline profile (human readable ART profile rules).
# AGP merges this with the Compose / AndroidX library profiles, expands the wildcards
# against the compiled classes, rewrites them through R8 and ships the result as
# assets/dexopt/baseline.prof. androidx.profileinstaller installs it after sideload;
# Play installs it with the APK.
#
# Paths covered: process start (Application / Graph / repositories), first home frame
# (MainActivity, HomeScreen, HomeGrid, Dock, icons), page swipes, folder open/close and
# the App Library page. Rarely used screens (widget picker, split picker, file pin
# pickers, rename dialogs) are intentionally left to JIT.
#
# H = hot, S = startup, P = post-startup. ** matches any class or member.
